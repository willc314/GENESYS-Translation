\section{The Shape of the Outcome}

The four rejections divide evenly between two kinds of reason with two about access, and two about suitability:\\

The REST API requires administrative configuration the team
cannot perform, and the commercial interchange format is unavailable from a
University Edition licence. Neither is a judgement about the interface, and a
team with full access would reasonably have built something simpler, most likely
a single modern .NET program talking over HTTP with no runtime split at all.\\

The two about suitability would hold regardless of licensing. The Excel
Connector flattens relationships into rows and columns, and relationships are the
substance of what the translation carries. Direct database access targets an
undocumented store, bypasses the validation that keeps a model consistent, and
prevents the application from starting while a connection is open.\\
